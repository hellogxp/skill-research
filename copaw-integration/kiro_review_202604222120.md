| 字段 | 是否使用 |
|------|----------|
| `enabled` | ✅ 使用 |
| `encoder` | ✅ 使用 |
| `top_k` | ✅ 使用 |
| `min_score` | ✅ 使用 |
| `max_tools` | ❌ 未使用 |
| `token_budget` | ❌ 未使用 |
| `mandatory_tools` | ❌ 未使用 |

这 3 个字段是 PR 描述里提到的 "PR2: MCP tool filtering" 的预留字段，当前 PR 不需要。maintainer 可能会质疑为什么有未使用的配置。

### 问题 2（性能）：`_build_skill_hint()` 每次调用都执行 `load_config()`

文件: `src/qwenpaw/agents/react_agent.py` 第 389-393 行

```python
from ..config.utils import load_config
config = load_config()
sr_config = getattr(config, "semantic_routing", None)
```

SkillRouter 和 skill metadata 都做了缓存，但 `load_config()` 每次 `_build_skill_hint()` 都会调用。如果 `load_config()` 每次读磁盘，这是不必要的开销。

建议: 确认 QwenPaw 的 `load_config()` 是否内部有缓存。如果没有，考虑把 `sr_config` 也缓存起来（和 SkillRouter 一起）。如果有缓存，则无需修改。

---

### 问题 3（死代码）：`__init__.py` 的 `__getattr__` lazy import 未被使用

文件: `src/qwenpaw/routing/__init__.py` 第 50-68 行

`__getattr__` 里定义了 `SemanticRoutingConfig`、`IndexItem`、`SearchHit`、`RoutingResult`、`SemanticIndex`、`SkillRouter` 的 lazy import。但所有实际使用这些类的地方都是直接 import 子模块：

- `from ..routing.router import SkillRouter`（react_agent.py）
- `from ..routing import is_routing_available`（react_agent.py）
- `from .index import SemanticIndex`（router.py）
- `from .config import SemanticRoutingConfig`（router.py）

没有任何代码通过 `from qwenpaw.routing import SkillRouter` 来触发 `__getattr__`。

建议: 删掉 `__getattr__` 函数，或者保留但加注释说明这是为外部用户提供的公开 API（如果确实需要的话）。

---

### 问题 4（过时 docstring）：`router.py` 的 SkillRouter docstring 还提到 FAISS

文件: `src/qwenpaw/routing/router.py` 第 31 行

```python
persist_dir:
    Optional directory for FAISS index persistence.
```

FAISS 已经删了，改用 numpy 存储。应该改成：

```python
persist_dir:
    Optional directory for index persistence.
```

建议: 修改 docstring。

---

### 问题 5（潜在风险）：`_skill_meta_cache` 是类变量，多实例共享

文件: `src/qwenpaw/agents/react_agent.py` 第 479 行

```python
_skill_meta_cache: dict[str, tuple[float, dict[str, str]]] = {}
```

这是类级别变量，所有 QwenPawAgent 实例共享同一个 cache。如果有多个 agent 实例使用不同 workspace（不同 skills_dir），同名 skill 的 metadata 会互相覆盖。

当前风险: 低。QwenPaw 通常只有一个 agent 实例。但如果未来支持多 agent，这会是个 bug。

建议: 可以暂不修改，但加个注释说明这个限制。或者把 cache key 改成 `(skills_dir, name)` 而不是只用 `name`。
