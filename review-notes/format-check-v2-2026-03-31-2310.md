## 你报告的问题：Table 7 盖住左边文字

这是 LaTeX 浮动排版问题。Table 7 (`tab:llm-direct`) 在 Discussion section 中用 `[t]` 浮动。当页面空间不足时，`[t]` 表格会被推到下一页顶部，但如果同一页已经有其他浮动体（Table 6 context），LaTeX 可能把表格放在不理想的位置。

修复方案（选一个）：

方案 A（推荐）：把 Table 7 改为 `[!ht]`，强制就近放置：
```latex
\begin{table}[!ht]   % 改为 !ht
```

方案 B：把 Table 7 的内容合并到 Discussion 的文字段落中（用 inline 方式），去掉浮动。

方案 C：在 Table 7 前加 `\clearpage` 或 `\FloatBarrier`（需要 `\usepackage{placeins}`），强制先排完之前的浮动体。

方案 D：把 Table 7 移到 Appendix，Discussion 中只用文字描述数据。

我推荐方案 A，最简单。如果还是溢出，试方案 C。

## 新发现的问题

### 问题 1（低）：Discussion section 中 Table 7 的 caption 很长

```latex
\caption{Decomposition vs.\ direct selection. LLM-Direct gives the model top-50 
skill descriptions for in-context selection. \textbf{7B+SAD outperforms 72B 
LLM-Direct} despite $10\times$ fewer parameters.}
```

Caption 有 3 句话，其中第 3 句用了 `\textbf`。ACL style 通常不建议在 caption 中用 bold（caption 本身已经是 small font）。而且 caption 过长会占用更多垂直空间，加剧浮动问题。

建议缩短为：
```latex
\caption{Decomposition vs.\ direct selection. 7B+SAD outperforms 72B LLM-Direct 
despite $10\times$ fewer parameters.}
```

### 问题 2（低）：9 个表格中有 8 个用 `[t]`，1 个用 `[h]`

Table 9 (DAG pilot, Appendix) 用 `[h]`，其他全部用 `[t]`。在 Appendix 中 `[h]` 是合理的（appendix 通常希望表格就近出现），但如果 LaTeX 无法在当前位置放置，`[h]` 会 fallback 到 `[t]`，可能导致表格飘到意外位置。

建议改为 `[ht]` 或 `[!ht]`。

### 问题 3（低）：Conclusion 被大幅压缩

当前 Conclusion 只有 3 句话：
```
We formalized Compositional Skill Routing and presented SkillWeaver...
On CompSkillBench, oracle retrieval is near-perfect...
Code, data, and CompSkillBench will be released upon acceptance.
```

这比之前的版本短了很多。虽然简洁是好的，但 Conclusion 通常需要 (1) 总结贡献 (2) 核心发现 (3) future work。当前缺少 future work 的提及（之前有 "iterative multi-round SAD"）。

建议加回一句 future work："Promising directions include iterative multi-round SAD, adaptive hint selection, and decomposition-aware fine-tuning."

### 问题 4（低）：Analysis section 被大幅压缩

当前 Analysis section 只有 2 句话（error analysis + oracle retrieval），之前有 case study。压缩是为了控制页数，但 error analysis 是审稿人看重的部分。

如果页数允许，建议保留至少一个 case study 例子。如果不允许，当前的压缩版本也可以接受。
