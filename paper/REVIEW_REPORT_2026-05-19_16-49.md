## 核心优势

1. **真实MCP生态数据**: 从GitHub SKILL.md转向2,209个真实MCP server skills，大幅提升了benchmark的实际意义和可信度

2. **统计严谨性**: Wilcoxon signed-rank test + Bootstrap 95% CI，诚实报告CatR@1不显著(p=0.17)，DA高度显著(p<10⁻⁶)

3. **机制分析精确**: DA-conditioned分析揭示SAD是"粒度校正器"而非"词汇对齐器"——当DA=1时两种方法CatR@1相同(41% vs 41%)

4. **收敛理论**: 基于有限集合的pigeonhole argument证明收敛必然性，实验验证1次迭代即可

5. **Transfer实验**: Category transfer (+35.6%) 和 skill held-out (+23.2%) 证明SAD不是memorization

6. **端到端验证**: 76.7% Chain Completion Rate证明routing结果可执行

7. **诚实的claim-evidence匹配**: 不overclaim CatR@1的改进，明确指出是directional improvement

## 核心问题（按严重程度排序）

### P0 (必须解决)

**无**

### P1 (强烈建议解决)

1. **CatR@1改进不显著(p=0.17)是潜在弱点**
   - 问题: 审稿人可能认为"核心routing指标没有显著改善"是致命缺陷
   - 当前处理: Discussion中诚实讨论，解释SAD是granularity corrector
   - 风险: 部分审稿人可能不接受"DA显著但CatR@1不显著"的论文
   - 建议: 当前处理已经是最佳策略（诚实+机制解释）。可考虑在Abstract中更突出DA作为primary metric，弱化CatR@1的地位。或者增加一个"DA-conditioned CatR@1"作为secondary metric（当DA=1时CatR@1=41.2%，这个数字更有意义）

2. **模型对比范围缩小**
   - 问题: 从5个模型(7B-72B)缩减到Qwen2.5-7B + qwen-max spot-check(50 queries)
   - 风险: 审稿人可能质疑"只在一个7B模型上验证"
   - 建议: 如果时间允许，增加Llama-3.1-8B或Mistral-7B的结果（至少50 queries）

### P2 (建议解决)

1. **Retriever从BGE-large降级到all-MiniLM-L6-v2**
   - 问题: 384d vs 1024d，可能影响retrieval ceiling
   - 建议: 在Discussion中已提到"domain-adapted or larger encoders may improve"，可保持

2. **Compose stage未独立评估**
   - 问题: 论文承认compose stage缺乏ground-truth compatibility annotations
   - 建议: 当前"architectural completion"定位合理，pilot study(76.7% CCR)提供了间接验证

3. **Human-style queries的strict DA很低(8.5%→21.5%)**
   - 问题: 虽然DA±1更合理(30%→48.3%)，但strict DA数字看起来不好
   - 建议: 当前解释合理（open-ended step boundaries），可保持

4. **ReAct baseline DA=0%需要更多解释**
   - 问题: "collapses multi-step tasks into single actions"——为什么？
   - 建议: 增加1-2句解释ReAct为何在compositional routing上失败

## 具体修改建议

### P1-1: 强化DA作为primary metric的论证

在Abstract或Introduction中增加：

```
We argue that decomposition accuracy (DA)---whether the model produces the correct 
number of sub-tasks---is the appropriate primary metric for compositional routing: 
our DA-conditioned analysis shows that correct granularity is a prerequisite for 
effective retrieval (CatR@1 rises from 34% to 41% when DA=1), making DA the 
gating factor in the pipeline.
```

### P1-2: 增加一个模型的验证

如果时间允许，在50 queries上跑一个Llama-3.1-8B或Mistral-7B，报告DA improvement是否一致。

### P2-4: ReAct解释

在Baselines段落增加：

```
ReAct collapses because its think-act-observe loop lacks explicit decomposition 
guidance: the agent attempts to solve the entire multi-step query in a single 
action selection, producing "use tool X to do everything" rather than structured 
sub-task decomposition.
```

## 审稿人可能的Questions for Authors

1. **Q1 (Critical)**: CatR@1 improvement is not statistically significant (p=0.17). How do you justify the paper's contribution if the primary routing metric doesn't significantly improve?

2. **Q2 (Important)**: You only evaluate on Qwen2.5-7B (300 queries) with a spot-check on qwen-max (50 queries). How confident are you that SAD generalizes across model families?

3. **Q3**: The retriever uses all-MiniLM-L6-v2 (384d). Have you tried larger encoders (BGE-large, E5-large)? The CatR@10 of 70% suggests retrieval ceiling may be limited by encoder capacity.

4. **Q4**: The compose stage (Eq. 4) is described but not independently evaluated. How do you know the compatibility scoring actually helps?

5. **Q5**: Transfer experiments show +35.6% DA gain under category transfer. But the CatR@1 gain is only +9.2% (0.195→0.213). Does this mean SAD helps decomposition but not retrieval in transfer settings?

6. **Q6**: The convergence analysis shows DA plateaus at Round 1 but CatR@1 peaks at Round 2. Why not default to T=2?
